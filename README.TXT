■ 概要

Free Signage Kit (FSKit) は、Windows及びLinuxでサイネージを実現するためのブラウザキットです。

Pythonベースで、Chromium エンジンを採用する LGPLライセンスの下で、
Strollon 0.7.0.0から作成されました。

________________________________________________________________________________________________
■ 主な機能

・フルスクリーンのキオスクモード
・右クリックメニューの無効化
・終了ショートカットキー
・config.toml による設定管理
・ホームページ表示, サブタブ機能(縦型タブパネル)
・接続断・読み込み失敗時に、指数バックオフ式で自動的に再読み込み
・自動復旧
・ダウンロードを許可するホストをドメインホワイトリストで指定
・マイク / カメラ / 位置情報へのアクセス許可をドメインホワイトリストで指定
・一定間隔、または指定時刻での自動フルリスタート
・ログ出力レベルの設定(debug / info / warn / error)
・Chromium起動フラグの追加指定、VA-APIハードウェアデコード等のカスタマイズ
