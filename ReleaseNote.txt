# 0.5.0.0
[改善]
・Linux amd64/aarch64版にdeb/rpm/tarballを追加しました。

# 0.4.0.0
[新機能]
・ダウンロードをドメインホワイトリストで許可できるようになりました (*可能)
・マイク / カメラ / 位置情報をドメインホワイトリストで指定できるようになりました (*不可)
・ホームページの読み込みに失敗時の再試行間隔を、指数バックオフに変更
 (browser.home_retry_ms / home_retry_max_ms)
・一定間隔か指定時刻でアプリを再起動する「ハードリスタート」機能を追加しました
 (kiosk.restart_interval_hours / restart_at)
・ログ出力を4段階(debug / info / warn / error)で設定できるようになりました
 (logging.level)

[改善]
・ページのレンダラープロセスがクラッシュした場合、自動的に再生成し復旧するようになりました
・config.toml の項目を型ごとに検証するようにしました

[修正]
・非アクティブなタブ(背景タブ)で window.open() 等による新規タブ作成が機能しない不具合を修正
・タブタイトルにページの document.title がリッチテキストとして解釈され得た問題を修正しました
・ホームページの読み込みに失敗した場合に自動復旧しない不具合を修正しました
・タブを閉じる際、破棄処理と競合しクラッシュする可能性があった問題を修正しました
